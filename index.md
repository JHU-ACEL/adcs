# Spacecraft Attitude Determination and Control (EN.530.685)

## Course Description
In this course, students will learn the fundamentals of how a spacecraft attitude (i.e., orientation in inertial space) is determined and controlled.
In particular, this course will study how to model the kinematics and dynamics of a rigid body in space, the representation of its attitude for different applications, how to use state estimation and sensor fusion techniques to estimate the attitude using noisy sensor measurements, and how to control the attitude using passive and active control techniques.
Through the course of the semester, students will build up a spacecraft simulation framework using Google's jax scientific programming library and applications studied will include satellites, rockets, and quadrotors/drones.
Students are expected to have a strong foundation in linear algebra and differential equations as well as experience with a high-level programming language (e.g., Python or Julia).
